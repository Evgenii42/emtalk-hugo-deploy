BEFORE YOU BEGIN

A few useful details.

How many options can I compare?

Add one to eight options. One to three go straight to Pros & Cons. Four to eight begin with pairwise comparison; you can then explore up to three options through their pros and cons.

Where are my decisions saved?

Your current draft and named copies are saved in this browser when storage is available. Clearing browser data, private browsing or changing devices can affect access. Export a JSON file to keep a portable backup. If saving is blocked, the workspace explains how to keep your current work.

Can I return to a decision?

Yes. Opening DOS resumes an available local draft. Named copies are in Saved decisions. You can also import a previously exported decision JSON file in the web workspace. Compatible files exported under the earlier Decision Matrix name still work.

Does the web workspace use AI or a cloud account?

No. The current web preview uses local calculations. Web AI, sign-in and cloud sync are not connected, and decisions do not automatically transfer to the Android app.
